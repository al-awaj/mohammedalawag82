| API | Fastify | 5.x | أداء عالٍ، مخططات JSON، plugins للأمان |

## 4. مبادئ معمارية ملزمة

1. **قاعدة البيانات مصدر الحقيقة**: القيود الحرجة (منع التعارض، توازن القيود، عدم تجاوز الاسترداد، عدم تكرار التسوية) تُفرض بقيود ومشغلات وأقفال، والخدمة تتحقق أيضًا لإعطاء رسائل واضحة.
2. **لا منطق أعمال في الواجهات**: الواجهات تعرض وتستدعي فقط؛ إخفاء الأزرار ليس بديلًا عن التحقق في الخادم.
3. **Snapshot لا Reference للقيم المالية**: الحجز يحمل نسخة من السعر والعربون والعمولة والسياسة والشروط.
4. **Append-only للسجلات الحساسة**: سجل التدقيق، أسعار الصرف، القيود المحاسبية، أحداث الحالة.
5. **Outbox للأحداث الخارجية**: الإشعارات تُكتب في نفس المعاملة إلى `message_outbox`، ثم يرسلها العامل؛ لا رسالة "تم الدفع" قبل التحقق.
6. **Idempotency**: عمود `idempotency_key` فريد في الجداول التي تنشئ آثارًا مالية/حجوزات.
7. **نطاق الدولة في الصلاحيات**: الدور يُسند للمستخدم إما عالميًا أو لدولة محددة، ويُطبق في الاستعلامات.
8. **إصدار الواجهات**: كل المسارات تحت `/v1`.

## 5. صيغة الأخطاء

```json
{ "error": { "code": "AUTH_INVALID_CREDENTIALS", "message": "بيانات الدخول غير صحيحة", "details": null } }
```
الرسالة تُترجم حسب `Accept-Language` أو لغة المستخدم المفضلة.
