# دليل لوحة الإدارة

> لفريق المنصة. القائمة تُظهر لكل موظف ما تسمح به أدواره فقط، والتحقق الفعلي في الخادم. اللغة تُبدَّل من زر العربية/English أعلى الصفحة. كل إجراء حساس يُسجَّل في «سجل التدقيق» باسم من نفّذه وسببه.

## 1. الأدوار الجاهزة

| الدور | المسؤولية |
|---|---|
| مسؤول النظام | كل شيء، بما في ذلك الأدوار والإعدادات ومزودي الدفع. لشخصين على الأكثر. |
| مدير | كل شيء عدا الأدوار والإعدادات وإعدادات الدفع. |
| مشرف خدمات | طلبات التسجيل، أصحاب الخدمات، التصنيفات والأنواع، مراجعة ونشر الخدمات، التقييمات. |
| موظف حجوزات | متابعة الحجوزات وقبولها وإلغاؤها. |
| موظف مالي | المدفوعات، الاستردادات، المستحقات، التسويات، الصناديق، أسعار الصرف، التقارير والتصدير، المطابقة. |
| موظف دعم | عرض العملاء والحجوزات والخدمات، ومراجعة النزاعات دون قرار. |

يمكن إنشاء أدوار مخصصة من «الموظفون والأدوار»، وتقييد أي دور بدولة واحدة. لا يمكن لموظف منح صلاحيات لا يملكها، ولا تعديل أدواره بنفسه.

## 2. العمليات اليومية

### طلبات التسجيل (مشرف خدمات)
«طلبات التسجيل» ← افتح الطلب ← راجع البيانات وحمّل كل وثيقة (كل تحميل مسجل).
- **طلب معلومات**: يعود الطلب لصاحبه مع ملاحظتك ليستكمل.
- **قبول**: يُنشأ حساب صاحب الخدمة ثم تُحدَّد أنواع الخدمات المسموح له بها من «أصحاب الخدمات».
- **رفض**: السبب إلزامي، ويمكن لصاحب الطلب التقديم من جديد.
- «أصحاب الخدمات»: الإيقاف (يخفي خدماته فورًا) وإعادة التفعيل، وأهلية التسوية المرحلية.
- «طلبات تعديل البيانات»: تغيير الاسم التجاري أو نوع النشاط أو بيانات التحويل لصاحب خدمة مقبول ← **اعتماد** (يُطبق فورًا) أو **رفض** مع السبب. بيانات التحويل تظهر وتُعتمد فقط لمن يملك صلاحية «عرض البيانات المالية لأصحاب الخدمات»، ولا تُحفظ قيمتها في سجل التدقيق.

### الخدمات (مشرف خدمات)
«الخدمات» ← المرسلة للمراجعة ← تحقق من الصور والوصف والسعر وسياسة الإلغاء ← **نشر** أو **إعادة للتعديل مع السبب**. يمكن إيقاف نشر خدمة منشورة. تغيير السعر لا يمس الحجوزات السابقة (يُحفظ السعر والسياسة وقت الحجز).

### الحجوزات والتقويم (موظف حجوزات)
- «الحجوزات»: البحث برقم الحجز أو الطلب وتصفية بالحالة والتاريخ؛ صفحة الحجز تعرض السجل الكامل والمدفوع والمتبقي.
- «طلبات الإلغاء»: الإلغاءات التي تتطلب سياستها مراجعة؛ القرار يطبق السياسة أو مبلغًا تحدده مع السبب.
- الإلغاء الإداري: تختار مبلغ الاسترداد، ويعتمده موظف آخر (لا يعتمد الشخص ما طلبه).
- «التقويم»: كل الحجوزات والحجوزات المؤقتة والخارجية والإغلاقات في دولتك.

### المدفوعات (موظف مالي)
- البطاقات تُؤكَّد تلقائيًا من إشعار البوابة الموقّع؛ لا يوجد زر «تأكيد يدوي» لدفعة بطاقة.
- **التحويل البنكي/الدفع المباشر**: افتح الدفعة ← حمّل الإثبات ← أدخل **المبلغ المتحقق منه** (قد يختلف عما أبلغ به العميل) ← اعتماد أو رفض مع السبب. المراجعة والاعتماد صلاحيتان منفصلتان.
- الدفعات التي اختلف مبلغها أو وصلت بعد انتهاء الحجز المؤقت تظهر للمراجعة ولا تُؤكَّد تلقائيًا.

### الاستردادات (موظف مالي، بمبدأ العينين الأربع)
الاسترداد يُنشأ من الإلغاء أو قرار النزاع أو يدويًا لحجز منتهٍ دون خدمة ← **اعتماد** (من موظف غير من طلبه) ← **تنفيذ** (عبر البوابة، أو تسجيل المرجع البنكي) ← يكتمل عند تأكيد المزود. لا يمكن تجاوز المبلغ المدفوع فعلًا، ولا تكرار الاسترداد.

### المستحقات والتسويات (موظف مالي)
- «مستحقات أصحاب الخدمات»: تصبح المستحقات «مستحقة» عند إتمام الحجز (أو بعد مراجعة إن كانت الدولة تشترطها). المبالغ المحجوزة لنزاع لا تدخل أي تسوية.
- «التسويات» ← معاينة لصاحب الخدمة والعملة ← إنشاء ← **اعتماد** من موظف آخر ← تحويل المبلغ فعليًا ← **تسجيل الدفع** بمرجع التحويل. عند الفشل: «فشلت» مع السبب، فتعود المستحقات متاحة.
- **التسوية المرحلية**: فقط لمن فُعّلت أهليته بنسبة قصوى ومرجع اتفاق، وتُخصم عند الإتمام.

### النزاعات والشكاوى
افتح النزاع ← اطلب معلومات أو ردًا من الطرف الآخر ← (اختياري) **احجز** جزءًا من مستحق صاحب الخدمة بالمبلغ المتنازع عليه فقط ← **القرار** مع مبرر مكتوب: رفض (يُحرر الحجز) أو قبول مع استرداد يُحمَّل على صاحب الخدمة أو على المنصة ضمن الحد المسموح ← الإغلاق. الشكاوى العامة (دون طرف آخر) تُدار بنفس الشاشة.

### التقارير والمستندات والمطابقة
- «التقارير»: لكل دولة وعملة، وأي تحويل للعملات يتم فقط بسعر صرف موثق ومؤرخ. التصدير CSV يحتاج صلاحية التصدير ويُسجَّل.
- «المستندات»: الفواتير والإيصالات وإشعارات الاسترداد والتسوية بأرقام متسلسلة لكل دولة وسنة، ثابتة بعد إصدارها، وقابلة للطباعة بالعربية والإنجليزية.
- «المطابقة»: أدخل كشف البوابة أو البنك لفترة ← تظهر الفروقات بندًا بندًا لمتابعتها وإغلاقها بملاحظة. «فحوص الاتساق» يجب أن تكون صفرًا دائمًا.

## 3. الإعداد (مسؤول النظام)

- «الدول والعملات والشروط»: الدول وعملاتها ومنطقتها الزمنية، أسعار الصرف (سجل غير قابل للتعديل)، نسخ الشروط والأحكام (النسخة المنشورة لا تتغير؛ تُنشر نسخة جديدة).
- «الإعدادات»: مدة الحجز المؤقت (افتراضي 15 دقيقة، عامة أو لكل دولة) وغيرها؛ تغيير الإعداد لا يغيّر الحجوزات أو العمليات السابقة.
- «طرق ومزودو الدفع»: التكامل يحفظ **اسم متغير السر** فقط (`secretRef`)، والسر نفسه في `secrets.env` على الخادم. اختبر قبل التفعيل. سجل أحداث الدفع في نفس الصفحة.
- «العمولات»: نسبة أو مبلغ ثابت، على مستوى الدولة أو نوع الخدمة أو صاحب الخدمة؛ الأدق ينطبق، ويُحفظ مع كل حجز. لا توجد رسوم إضافية على العميل فوق السعر المعلن.
- «الصناديق والحسابات»: لا يمكن تعطيل صندوق برصيد أو بطريقة دفع نشطة.
- «الإشعارات»: القنوات والقوالب باللغتين وسجل الإرسال، وقواعد التذكير مع قناة كل قاعدة.
- «المساعدة والأسئلة الشائعة» (صلاحية إدارة المحتوى): أسئلة وأجوبة باللغتين لكل دولة أو لكل الدول، موجهة للعملاء أو لأصحاب الخدمات أو للجميع. تظهر في الموقع والتطبيق ولوحة أصحاب الخدمات بعد تفعيل «منشور»، وتُخفى بإلغاء النشر (لا تُحذف).
- **صفحات أصحاب الخدمات العامة**: تظهر للعملاء فقط إذا سمح إعداد «إظهار هوية أصحاب الخدمات» في الدولة وسمح صاحب الخدمة؛ وإلا لا توجد الصفحة أصلًا.
- «قالب عقد الحجز» (صلاحية إدارة المحتوى): نص العقد باللغتين مع متغيرات مثل `{{customerName}}` و`{{total}}`. كل حفظ يُصدر **نسخة جديدة** تنطبق على الحجوزات القادمة فقط؛ كل حجز يحتفظ بالنسخة التي أُنشئ عليها. النص المقترح مسودة **يجب مراجعتها قانونيًا** لكل دولة قبل الاعتماد. يظهر العقد للعميل وصاحب الخدمة والإدارة بصيغة طباعة وPDF.
- «التصنيفات وأنواع الخدمات»: زر «استيراد الكتالوج الجاهز» يضيف تصنيفات وأنواعًا وحقولًا جاهزة لخدمات المناسبات (قاعات، تصوير، ضيافة، تنسيق، صوتيات، تأجير، تجميل، تنظيم، سيارات) دون إنشاء أي خدمات أو أسعار، ويتجاوز الموجود. لكل نوع: الوثائق المطلوبة لكل خدمة (يرفعها صاحب الخدمة قبل إرسالها للمراجعة وتظهر للمراجع في صفحة الخدمة)، وسياسة إلغاء افتراضية من سياسات المنصة، وحقول من الأنواع: نص، رقم، اختيار، تاريخ، **وقت**، **موقع على الخريطة**… ولكل تصنيف صورة تظهر في الصفحة الرئيسية.
- «الإعدادات» → `payments.partial_min_percent`: أقل نسبة من المتبقي يمكن للعميل دفعها مبكرًا (100 = لا دفعات جزئية خارج خطة الأقساط). خطط الأقساط يحددها صاحب الخدمة لكل خدمة أو باقة (نسبة من المتبقي | عدد الأيام قبل الموعد)، وتُجمّد مواعيدها مع كل حجز، ولها قاعدة تذكير «قبل استحقاق قسط».
- «سجل التدقيق»: للقراءة فقط؛ تصفية بالفاعل والكيان والإجراء.

## 4. قواعد لا استثناء فيها

- لا حذف ولا تعديل للقيود المالية أو سجل التدقيق؛ التصحيح بعملية عكسية معتمدة.
- لا يعتمد شخص ما طلبه (الاستردادات، التسويات).
- لا تُشارك كلمات المرور، ولا تُرسل أسرار الدفع عبر البريد أو المحادثات.
